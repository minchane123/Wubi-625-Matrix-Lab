# 五笔625炼药台 (Wubi 625 Matrix Lab)

这是一个专为**学习五笔**及**希望进阶五笔打字水平**的练习者打造的高频候选字词库生成工具。

本项目使用的是 **五笔86版（微软 Windows 系统自带的默认版本）** 码表。

## 💡 核心进阶理念

五笔打字真正的质变，并不在于能熟练“拆字”，而在于**建立“字”与“编码”之间的双向直接映射**。

*   **新手期**：看到字 -> 大脑拆解字根 -> 反应出键位 -> 敲击键盘。
*   **进阶期**：想到字 -> 手指条件反射敲出编码（甚至不用拆字）。

当映射建立起来之后，拆字这个步骤反而会拖慢你的思维速度。本项目的 625 组合矩阵，就是为了帮你**直观地建立这种条件反射**，通过反复查阅和背诵，把高频字和常见字的前两码（甚至全码）刻进你的肌肉记忆里。

### 🔑 为什么是“前两码”？(Why the first two codes?)

因为**中文中的词语多为两个字**。

在现代汉语中，双字词占据了日常交流的绝对主导地位。而在五笔（86版）的规则中，**双字词的编码方式正是：第一字的前两码 + 第二字的前两码**。

这意味着，只要你熟练掌握了这 625 个前两码的组合（A-Y，不含 Z），你不仅在打单字时能秒出二级简码，在打词组时，也能直接实现“两字四键”的极速盲打。掌握了前两码，你就掌握了五笔打词的半壁江山。

## ✨ 核心特性

1. **二级简码矩阵**：直观展示 25x25 个前两码对应的首选单字，助你建立初步的条件反射。
2. **常字优先，词频排序**：对于每个前两码前缀，优先提取《现代汉语常用字表（3500字）》，并严格按照现代汉语真实词频（数字越小越靠前）降序排列，高度还原真实的输入直觉。
3. **生僻字补齐**：如果某个前缀下的常用字不足 10 个，会自动抓取非常用字来补齐候选位。
4. **视觉高亮**：所有属于 3500 常用字的字，在 Excel 中均使用**淡绿色高亮**标出，一眼看清必须掌握的核心字根。
5. **编码补全**：候选字附带该字的剩余全码（例如“戒k”、“茅bt”），帮助你在敲击前两码后，立刻知道第三码或第四码该按什么，实现无缝盲打。
