# 五笔625炼药台 (Wubi 625 Matrix Lab)

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)
![License](https://img.shields.io/badge/License-MIT-green)

这是一个基于 Python 和 Excel 的五笔输入法（86版）进阶训练辅助工具。

This is an advanced training assistant tool for the Wubi input method (Version 86), generated via Python and Excel.

---

## 🇨🇳 中文说明

### 一、 项目契机

五笔打字初期的难点在“拆字”，但想要进阶到极速盲打，真正的瓶颈在于**建立“字”与“编码”之间的直接映射（双向映射）**。当看到一个字时，手指应直接敲出对应键位，如果在脑海中还要先过一遍“怎么拆”，速度永远无法突破。

在日常打字中，**双字词占据了绝大比例**，而五笔双字词的编码规则是“首字前两码 + 次字前两码”。这意味着，只要彻底掌握了 25 个字母组合出的 **625 种前两码**，就能在打词组时实现无重码极速盲打。

现有的五笔工具多侧重于字根表和生僻字反查，缺乏针对“高频前两码”和“真实字频排序”的直观训练工具。为此，本项目通过提取系统纯净码表与权威现代汉语字频表，自动生成排版精美、按频率排序的 Excel 矩阵表及 PDF 打印版，辅助训练者建立肌肉记忆。

### 二、 项目实现的功能

本脚本运行后，会生成排版精美的 Excel 文件（`五笔625炼药台.xlsx`）以及自动导出的 PDF 文件（`五笔625炼药台.pdf`）：

1. **全量前两码矩阵展示（Sheet1）**
   - 横向与纵向均为 A-Y（不含 Z）的 25 个字母。
   - 矩阵交叉点展示该两码组合下的最高频首选字。
   - 第 2 列单独列出 25 个一级简码，与首码按行对齐，方便集中记忆。

2. **真实词频排序与过滤（Sheet2）**
   - 摒弃了基于笔画排序的传统字表，接入了 `hanzi_db.csv`（基于现代汉语语料库的真实单字频率排名）。
   - 所有候选字严格按照真实字频从低到高（数字越小越常用）排序。
   - **自动过滤极低频字**：字频排名大于 6000 的字将被直接剔除，避免生僻字干扰视线。

3. **三色分级视觉高亮**
   根据字频排名，对单元格背景进行柔和着色：
   - **淡绿色**：前 2500 字（日常文本覆盖率极高，必须形成肌肉记忆）。
   - **淡蓝色**：2501 - 3500 字（高频常用字，要求熟练）。
   - **淡橙色**：3501 - 5000 字（进阶拓展字，了解即可）。

4. **极致的排版与阅读体验**
   - 编码后缀补全：候选字后附带该字的剩余全码（如 `戒k`）。如果该字已在 Sheet1 中出现则自动隐藏后缀。
   - **强制等宽对齐**：采用“新宋体”等宽特性，计算字符视觉宽度，利用空格补齐，实现左侧“字+码”紧贴，右侧灰色小字“四位频次”绝对垂直对齐（不足四位补零）。
   - **极细卡片分割线**：Sheet2 采用卡片式排版，超过 10 个候选字自动折行。每个前缀块只画极细的 `hair` 底线，绝不喧宾夺主，便于平板上阅读。

5. **自动生成 A4 完美排版 PDF**
   - 脚本在生成 Excel 后，会自动调用本地 Excel 引擎，直接导出一份 `.pdf` 文件。
   - **Sheet1** 精准切分为 A4 横向 2 页，每页固定带出首码列，字体大小适中，无惧挤压。
   - **Sheet2** 自适应一页宽，完美适配打印和平板阅读。

6. **纯本地运行**
   所有依赖的码表与字频数据均内置于 `data/` 目录下，无需联网下载即可一键生成。

### 三、 项目适用对象

1. **苦于五笔速度瓶颈的进阶者**：打字速度卡在 50-60 字/分钟，希望突破“拆字思维”，建立直接指法映射的用户。
2. **希望提升词组输入速度的用户**：希望掌握现代汉语高频词前两码，提升双字词盲打准确率的人。
3. **习惯于“看表背诵”的视觉型学习者**：喜欢通过高度结构化的矩阵、颜色和数字排序来建立空间记忆的用户。

### 四、 使用方法

1. 克隆本仓库到本地，或直接下载 ZIP 解压。
2. 确保已安装 Python 环境及所需依赖：
   pip install pandas openpyxl pywin32
   *(注：pywin32 用于调用本地 Excel 导出 PDF，请确保系统中安装了 Microsoft Office)*
3. 运行主脚本：
   python generate.py
4. 运行完成后，在 output/ 目录下即可找到生成的 .xlsx 和 .pdf 文件。

### 五、 数据说明

- **系统码表**：提取自 Windows 系统自带的微软五笔（86版）。
- **字频数据**：来自开源项目 hanziDB.csv 中的单字语料库频率排名。
- 本项目生成的 Excel 中，字体统一采用“新宋体”以确保跨平台的字符宽度对齐。

## 🇬🇧 English Description

### I. Background & Motivation

The initial challenge of learning Wubi is "character splitting" (拆字). However, the real bottleneck to achieving blind typing is establishing a **direct bidirectional mapping between characters and codes**. When a user sees a character, their fingers should instinctively hit the keys. If the brain still processes "how to split this character" first, the typing speed will never break through the limit.

In everyday typing, **two-character words dominate the modern Chinese language**. According to Wubi rules, the code for a two-character word is: **the first two codes of the first character + the first two codes of the second character**. This means that mastering the **625 two-code combinations** generated by the 25 letters allows for extremely fast, blind typing of words without candidate selection.

Existing Wubi tools mostly focus on radical charts or reverse-looking up rare characters. There is a lack of training tools tailored for "high-frequency two-code prefixes" and "real word frequency sorting." To address this, this project extracts clean system code tables and authoritative frequency data to generate a beautifully formatted, frequency-sorted Excel matrix and PDF, helping users build muscle memory.

### II. Features

Running the script generates an Excel file and automatically exports a PDF (五笔625炼药台.xlsx & .pdf):

1. **Full Two-Code Matrix (Sheet1)**
   - Both horizontal and vertical axes are A-Y (excluding Z).
   - The intersections show the highest-frequency primary character for each two-code combination.
   - The second column exclusively lists the 25 Level-1 short codes, aligned by rows for concentrated memorization.

2. **Real Word Frequency Sorting and Filtering (Sheet2)**
   - Integrates hanzi_db.csv (based on a real modern Chinese corpus frequency ranking).
   - All candidates are strictly sorted by real word frequency (smaller numbers indicate higher frequency).
   - **Automatic filtering**: Characters ranked > 6000 are discarded to prevent rare characters from cluttering the view.

3. **Three-Tier Color-Coded Highlighting**
   - **Light Green**: Top 2500 characters (Must be muscle memory).
   - **Light Blue**: 2501 - 3500 characters (Requires proficiency).
   - **Light Orange**: 3501 - 5000 characters (Advanced expansion).

4. **Extreme Layout & Reading Experience**
   - Suffix completion: Candidate characters display their remaining full code (e.g., 戒k). Hidden if already in Sheet1.
   - **Strict Alignment**: Utilizes the monospaced properties of the "NSimSun" (新宋体) font. Width is calculated and padded with spaces to ensure the left side (Character + Code) is tightly packed, and the right side (4-digit frequency in small grey text) is perfectly vertically aligned.
   - **Hairline Dividers**: Sheet2 uses a card layout. Prefixes with >10 candidates wrap automatically. Only ultra-thin hair borders are drawn to avoid visual clutter.

5. **Automated Perfect PDF Export**
   - Automatically calls local Excel engine to export a .pdf.
   - **Sheet1** is perfectly split into 2 A4 landscape pages (without crushing the text).
   - **Sheet2** fits exactly to 1 page width.

6. **Fully Offline Operation**
   All required code tables and frequency data are bundled in the data/ directory.

### III. Target Audience

1. **Users facing a speed bottleneck**.
2. **Users wanting to improve phrase typing**.
3. **Visual learners** who prefer spatial memory.

### IV. Usage

1. Clone this repository or download the ZIP file.
2. Ensure Python is installed and install dependencies:
   pip install pandas openpyxl pywin32
3. Run the main script:
   python generate.py
4. Find the generated .xlsx and .pdf in the output/ directory.

### V. Data Sources

- **System Code Table**: Extracted from the built-in Microsoft Wubi (Version 86) on Windows.
- **Frequency Data**: Sourced from the open-source project hanziDB.csv.
- The "NSimSun" font is enforced in Excel to guarantee character width alignment across platforms.
